Deep Learning Models

This project investigates short-term traffic speed forecasting using the METR-LA dataset. The study compares five deep learning architectures: LSTM, TSFormer, STGCN, Hybrid LSTM+TSFormer, and Hybrid STGCN+TSFormer.

Forecasting Scenario

The model uses 12 historical time steps, representing 60 minutes of traffic history, to predict the next three time steps. These correspond to traffic speed predictions for 5, 10 and 15 minutes into the future.

04

Models Compared

MODEL 01

LSTM

Long Short-Term Memory network used to learn sequential temporal patterns in traffic speed data.

MODEL 02

TSFormer

Time Series Transformer using self-attention to capture temporal dependencies in the traffic data.

MODEL 03

STGCN

Spatio-Temporal Graph Convolutional Network designed to model spatial and temporal traffic relationships.

BEST PERFORMING MODEL
MODEL 04

LSTM + TSFormer

Hybrid architecture combining LSTM's sequential modeling capability with Transformer-based self-attention for temporal pattern learning.

MODEL 05

STGCN + TSFormer

Hybrid architecture combining STGCN for spatio-temporal feature extraction with TSFormer for deeper temporal dependency modeling.

Model Evaluation

Model performance was evaluated on the test set using four metrics: Mean Absolute Error (MAE), Mean Squared Error (MSE), Root Mean Squared Error (RMSE), and Mean Absolute Percentage Error (MAPE).

07

Conclusion

The experiments showed that the Hybrid LSTM + TSFormer achieved the best performance among the five evaluated architectures. The model produced the lowest MAE, MSE, RMSE and MAPE values, indicating more accurate and stable short-term traffic speed predictions on the METR-LA dataset.
